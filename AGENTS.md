# Local project records

- Keep project notes, task summaries, decisions, implementation reports, and command results in `local-data/`.
- After each substantial task, save a timestamped Markdown report with the task, files changed, commands executed, test/build results, and outstanding issues.
- Never write passwords, API keys, access tokens, cookies, or other credentials to logs or reports.
- Do not upload `local-data/` reports, backups, or other private project data to external services unless explicitly authorized.
- Do not run `git push`, publish a release, deploy the project, or upload backups without explicit permission.
- Preserve existing functionality, source code, Git history, and user data.
- Do not claim Codex chat transcripts are saved locally unless their storage has been verified.
